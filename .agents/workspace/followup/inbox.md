# Inbox

A drop box for new tasks and notes without colliding with edits to
`tasks.md`.

**Contract:**

- The user appends new items here, either directly or via
  `/followup add: <text>`.
- The agent only reads this file except during `/followup add:` and
  `/followup triage:`; triage moves items into `tasks.md` and clears this
  section.

**Format:** one item per bullet, optionally timestamped. Prefix with `!` for
anything urgent enough to interrupt current work.
